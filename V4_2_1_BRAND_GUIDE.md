# Brand use (why the icon changed in all these places)
Standard practice: one product mark, used the same way everywhere the product identifies itself.
| Place | Uses |
|---|---|
| Phone launcher icon | the X icon (adaptive: dark gradient + X glyph; fallback: the full tile; round version) |
| Android 12+ system start-up screen | the launcher icon (automatic) |
| In-app splash screen | the full icon tile with glow, name, "Version x.x.x" |
| In-app header | small icon tile + "My Workouts" + compact "Vx.x.x" chip |
| Page icon (favicon) | the icon tile |
| Creator credit | text "Designed by CB" (credit line, not a logo) |
Version text: compact "V4.2.1" inside the app where space is tight, long "Version 4.2.1" on the splash where there is room.
