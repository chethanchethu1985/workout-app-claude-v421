# Claude_V4.2 (changes since V4.1)
1. App name on the phone: "My Workouts" (no version in the name). Version label inside the app: Claude_V4.2 (versionName Claude_V4.2, versionCode 6).
2. New launcher icon built from your corrected CB logo, in the app colours (black with a soft blue glow, white monogram, blue underline). Round and rounded-square versions included.
3. Back / redo: "< Back" button on every main-workout and hands-free screen. It steps back one set or one item and removes the set you had logged, so you can do it again. Hands-free sections also have Back next to Stop.
4. YouTube links: paste a link in Workout Library (expand a workout, YouTube link box, Save) or in the Add/Edit form. A preview appears straight away with a Play here button and an Open in the YouTube app link. The preview also shows on the exercise screen. Works for built-in and your own workouts.
5. Move or swap workouts inside a week: Today screen, "Move or swap this workout". Swap two days, move the whole workout to another day, or tick only some exercises to move. "Undo all moves in this week" restores the original plan.
6. Splash screen stays about 6.5 seconds (animated logo, name, progress bar).
7. New logo everywhere (splash, header, icon).
8. Safe updates: same app ID and a fixed signing key (signing/debug.keystore) so future builds install over the old app with your data. More tab: Backup and safe updates card (save or share a backup file, restore from a file, automatic backup in Documents/MyWorkouts). Backups now include plan edits, library, templates, YouTube links and health records (manual file).
9. Media folder: Choose a folder and Sync all folders now open the Android folder picker directly (starts in Download). Sync with nothing saved opens the picker; access off opens the all-files settings. "Check folder access" shows what the app detects. Browser pages get a clear explanation instead of silently failing.
10. Extras: progress rings on the dashboard, sticky tabs, safe-area spacing for notches.
